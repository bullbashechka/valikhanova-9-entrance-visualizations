# Планы общих зон

Актуальные планы — вырезки, предоставленные заказчиком 24 сентября 2026 года:

- `section-1-common-areas.png` — исходный `1.png`.
- `section-2-common-areas.png` — исходный `2.png`.
- `section-3-common-areas.png` — исходный `3.png`.

Изображения скопированы без изменений. Границы вырезок и все показанные двери сохраняются. При моделировании 3D двери в соседние помещения размещаются на указанных местах; интерьеры этих помещений не моделируются. Технические помещения и прочие детали, оставшиеся на вырезках, служат ориентирами и не расширяют объём дизайна.

Предыдущие неточные вырезки и скрипт их генерации перенесены в `archive-original-crops`. Скрипт устарел: его маски не соответствуют исправленным вырезкам заказчика, и повторный запуск из корня проекта перезапишет актуальные планы.
