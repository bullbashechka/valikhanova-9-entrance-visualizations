# Секция 1 — согласованная геометрия для концепции

Обновлено: 28.09.2026. **Геометрия представленной версии согласована заказчиком как основа концепции.**

Открыть [комплект для просмотра](review.html): четыре перспективных вида, размеченный вид сверху, наложение сечения модели на утверждённый PNG, [разрез лестницы](previews/08-stair-section.svg), [планы уровней](previews/09-stair-levels.svg) и перечень условных параметров. Проверка чертежей описана в [разборе источников](source-audit.md), все проёмы — в [ведомости](source-register.md). [Редактируемая сцена Blender](../../models/section-1/section-1-geometry.blend).

## Основа и принятые решения

Модель построена в метрах. X соответствует направлению вправо на PNG; Y — вверх (координата PNG инвертирована); Z=0 — чистый пол первого этажа. Раздельные масштабы X/Y взяты из `stage-1/calibration.json`. Использованы исходные координаты измерений и контуров, без округления линейных размеров до 50 мм.

Контуры всех стен и проёмов сверены с PNG. В `stage-1` были 41 измерение секции 1 и четыре контура пола, но не готовая система стен. Дополненная трассировка находится в [geometry.json](geometry.json). Сечение реальных стен сцены на высоте 1,2 м экспортируется в [scene-section.json](scene-section.json); именно оно показано голубыми линиями на наложении. Линии измерений в CSV задают продольное положение проёмов; поперечное положение взято по границам соответствующей стены.

- Высота помещений — 3000 мм; потолок без опуска. Внутренние дверные проёмы и лифт условно 2100 мм, наружные и тамбурные двери — 2400 мм по ЭП.
- Все 11 измеренных дверных проёмов и четыре участка остекления сохранены. Двери закрыты в перспективах; стороны открывания показаны на размеченном виде сверху по символам PNG. Ширины из обмера относятся к проёмам, а не дверным полотнам.
- S1-19 имеет одно остеклённое полотно по плану. Для S1-16 и S1-23 принято открывание до 85°: условные ручки на 90° задевают соседнюю стену. Остальные распашные двери проверены до 90°; фурнитура не выбрана.
- Колясочная открыта в вестибюль, без перегородки и двери. Один условный объект коляски показывает масштаб и назначение зоны; его размещение не задаёт вместимость.
- Тамбур сохраняет исходный контур площадью около 5,174 м². Подпись PNG 5,50 м² сохранена отдельно; причина расхождения не установлена.
- Наружный вход: верхняя площадка −0,010, нижний подход −1,060; семь подъёмов по 150 мм, шесть проступей в пределах длины марша около 1799 мм. Верхняя площадка завершает подъём.
- От двери вестибюля площадка 0,000 ведёт по левому маршу к развороту +1,650, затем по правому обратному маршу к площадке второго этажа +3,300. Каждый верхний марш условно разбит на 11 подъёмов по 150 мм. Площадка +3,300 продолжается до внутреннего коридора; смоделированы локальные стены, окно и потолок верхнего фрагмента. Низ маршей наклонный, толщина условно 150 мм. Обведённая на наружном виде дверь ведёт на отдельную площадку −1,050, откуда лестница опускается к подвалу −2,250. Прямого перехода от неё к площадке 0,000 на разрезе нет. Источники: планы подвала, первого и типового этажей ЭП, стр. 13, 16, 19; разрез секции 1, стр. 22. Подвал и второй этаж представлены только фрагментами, необходимыми для завершения маршрутов; отделка этих этажей не прорабатывалась.
- Окна, навес, ограждения, подъёмник и фрагмент окружения имеют явно записанные условные параметры. Фасады на стр. 11 ЭП не позволяют однозначно определить вертикальные размеры четырёх оконных участков PNG. Приняты подоконник 900 мм и верх 2400 мм для предварительного показа.
- Референсы используются для следующего этапа отделки. Почтовые ящики и отдельная дверь колясочной с референса в сцену не перенесены. Нейтральные материалы и свет служат только чтению геометрии.

## Данные и повторное использование

`geometry.json` содержит общие отметки, площадки, марши, верхний контекст, число полотен и пределы открывания. Имена существующих проёмов сохранены; верхнее окно имеет ID `S1-U2-W01`. Верхние стены, окна и потолки выделены в коллекции `UpperWalls`, `UpperWindows`, `UpperCeilings`. Данные сцены встроены в `.blend` и сверяются при повторном открытии.

Для секций 2 и 3 повторно используются способы построения и проверки. Контуры, размеры, отметки и источники каждой секции должны задаваться отдельно. Проверенные 3D-маршруты перечислены в `review_routes`; реальные меши для схем экспортируются в `stair-review.json`.

## Файлы и редактирование

Основной результат — `models/section-1/section-1-geometry.blend`, Blender 5.2.1 LTS. Стены, полы, потолки, проёмы, лестницы, наружный вход, условные объекты и камеры распределены по коллекциям. Каждый элемент — отдельный объект с источником и статусом. У проёмов сохранены ID обмера, высота, сторона и тип открывания. PNG встроен в `.blend` в скрытой коллекции Reference; внешние текстуры не нужны.

В сохранённой сцене потолки, верхние части стен и навес присутствуют. Для проверочного вида сверху они скрываются или временно срезаются на высоте 1,2 м **только в процессе рендера**; этот срез не перезаписывает `.blend`.

Повторная сборка заменяет созданный файл `.blend`. Перед повторной сборкой ручные изменения нужно сохранить в отдельную копию либо перенести в `geometry.json`/скрипт. Сборщик не удаляет произвольные файлы.

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python-exit-code 1 --python verification/stage-2/build_scene.py -- --render
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python-exit-code 1 models/section-1/section-1-geometry.blend --python verification/stage-2/verify_saved_scene.py
python verification/stage-2/make_review.py
python verification/stage-2/verify_review.py
```

На macOS аналогичные команды:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 --python verification/stage-2/build_scene.py -- --render --draft
/Applications/Blender.app/Contents/MacOS/Blender --background --python-exit-code 1 models/section-1/section-1-geometry.blend --python verification/stage-2/verify_saved_scene.py
python3 verification/stage-2/make_review.py
python3 verification/stage-2/verify_review.py
```

`--python-exit-code 1` обязателен для автоматического запуска: Blender иначе может завершиться с кодом 0 после исключения Python. Страница просмотра собирается только после успешной проверки текущего хеша `.blend`.

Сборщик использует встроенный Python Blender; для подготовки страницы просмотра нужен Python с Pillow. Для повторного получения фрагментов источника используется системный Poppler; он не нужен для сборки модели.

## Проверки

[validation.json](validation.json) — проверка фактических отверстий в стенах трассировкой лучей, основных осей движения, размещения коляски и хеша PNG. [reopen-validation.json](reopen-validation.json) — независимое повторное открытие сохранённой сцены, проверка площадей четырёх зон, потолков, отметок, ступеней, встроенного PNG и наличия ресурсов. Дополнительно выполнен повторный рендер из сохранённого файла.

Визуально проверены четыре перспективы, срез сверху, наложение стен и отдельные схемы лестницы. Независимая проверка включает пять 3D-маршрутов с выборкой габарита 0,60 × 2,00 м, опорой под ногами, перепадами, просветом и открытыми дверями; движения десяти распашных проёмов проверены в десяти положениях. Два отрицательных контрольных примера подтверждают обнаружение низкого препятствия и отсутствующей площадки. Это геометрическая выборка, не нормативный расчёт.

Итог: **22 проверки сборки и 56 проверок повторного открытия пройдены**. Две независимые сборки дали одинаковые координаты мешей, топологию и материалы — [отчёт повторяемости](rebuild-validation.json). Ссылки и ресурсы страницы проверены статически, SVG-схемы — системным рендерером. Браузерная проверка текущей версии недоступна из-за отсутствующего `browser-service.mjs` в браузерном плагине; прежний результат Edge не переносится на обновлённую страницу. Подробности — [отчёт страницы](review-validation.json).
