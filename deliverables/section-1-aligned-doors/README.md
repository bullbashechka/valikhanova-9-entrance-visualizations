# Секция 1 — комплект для показа

Откройте `index.html` в браузере. Интернет не нужен.

В папке `images` находятся четыре перспективы 2560 × 1707 px и цветной вид сверху с длинной стороной 2560 px. `section-1.blend` — редактируемая сцена с упакованными ресурсами; `section-1-plan.png` — исходный план без изменений.

Согласованные правки: платформа подъёмника с управлением, металлическая подвальная дверь с небольшим матовым окном, сплошная внутренняя стена вместо двух вставок у квартирной двери, стена вместо двух отмеченных оконных проёмов слева, две двери слева в плоскости внутренней стены, древесная отделка двери лестницы с надписью «ЛЕСТНИЦА», указатель «ЛИФТ →».

Это доработанная концепция. Модель подъёмника условная, конкретное оборудование и фактические строительные размеры не подтверждены. Квартирная дверь сохранена; два синих элемента исходного PNG по уточнению пользователя представлены стеной.
